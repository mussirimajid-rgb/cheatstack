Web Design Cheat Sheet: 21 Rules for Clean Websites

Six groups of rules that make a website look professional: typography, spacing, colour, buttons, layout and speed. Every number here comes from a published standard (WCAG for contrast and tap targets, Google's Core Web Vitals for speed) or common design practice.

Type

  • Body text 16–18px
  • Line height about 1.5
  • 45–75 characters per line
  • Two typefaces at most

Spacing

  • 8-point grid: 8, 16, 24, 32, 48
  • More space between groups
  • Sections: 64px+ padding

Colour

  • 60-30-10 colour rule
  • Text contrast ≥ 4.5:1
  • Large text contrast ≥ 3:1
  • Accent colour = actions

Buttons

  • Tap targets ~44×44px
  • One primary button per screen
  • Labels start with a verb

Layout

  • Mobile-first, test at 375px
  • Most important thing top-left
  • Max width ~1,200px

Speed

  • Images as WebP or AVIF
  • LCP ≤ 2.5 s
  • INP ≤ 200 ms
  • CLS ≤ 0.1

5 font pairings that always work (all free on Google Fonts)

  1. Inter + Playfair Display
  2. Montserrat + Merriweather
  3. Space Grotesk + Inter
  4. Poppins + Lora
  5. DM Sans + DM Serif Display
